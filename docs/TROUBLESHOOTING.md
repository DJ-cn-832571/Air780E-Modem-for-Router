# 故障排查

- 找不到软件包：确认已配置第三方源，在 LuCI 更新列表后搜索 `luci-app-air780e`。更新失败先检查路由器 DNS、时间、HTTPS 与 GitHub 可达性。
- 依赖安装失败：使用本机固件官方源，检查空间和内核驱动版本；禁止 `--force-depends` 或混装其他内核驱动。本包使用 opkg，apk 固件需单独打包。
- USB 连接错误：检查供电和数据线，拔插后等待重枚举；只连接一台模块。查看 `/dev/ttyACM*`，确认 kmod-usb-acm 与 ECM 驱动存在。
- DHCP 等待超时：确认模块脚本匹配，USB ECM 开启，无 192.168.10.0/24 子网冲突。
- DHCP 正常但 4G 验证失败：确认 SIM 数据业务和信号，检查模块转发；诊断会区分模块 DNS 与 HTTPS。验证绑定模块源地址，不以 WAN 或 VPN 的成功代替 4G 成功。
- 更新后旧页面：刷新网页，必要时重启 uhttpd；不要重启整个路由器来代替故障定位。
- 烧录工具下载失败：先「准备固件工具」，检查 GitHub、Ubuntu 软件源、合宙 CDN、临时空间。烧录前必须通过资源校验与脚本编译。
- 邮件认证失败：核对授权码及 SSL/STARTTLS，保存配置后恢复测试。投递结果未知不会自动重发，以免重复泄露验证码。
- 短信发送结果未知：先查看已发送记录，不重复点发送。短信中心接受不代表送达。

## 卸载与数据

`opkg remove luci-app-air780e` 停止常驻服务，保留 `/etc/air780e/`。该目录含短信及授权码，仅 root 可读。软件源行和公钥可从 `/etc/opkg/customfeeds.conf`、`/etc/opkg/keys/af5c2a6ce4ab8132` 删除；不要删除其他软件源或信任密钥。

彻底清理前自行备份。永久删除数据无法通过软件恢复，因此没有默认自动清理命令。软件源移除和插件卸载不会自动还原此前配置的 WAN、VPN 或 IPv6 策略，参见 NETWORK.md。
